# 在一起的每一天 · Love Diary

本地静态网页。解压后用浏览器打开 `love-diary/index.html`。
（网易云歌单导入、一起听需要联网；若本地直接双击打开时提示音或接口异常，可用任意本地静态服务器打开本目录。）

## 目录

```
love-diary/
  index.html
  css/style.css
  assets/notify.wav     ← 消息提示音
  assets/keepalive.wav   ← 后台保活循环音（极低音量）
  js/
    01-core.js          存储、状态、首页
    02-chat.js          聊天收发
    03-proactive.js     主动消息 / 来电 / 来信
    04-social.js        朋友圈、陪伴、记账、信件等
    05-tarot.js         塔罗
    06-notify.js        后台通知、提示音、保活
    07-together.js      一起听歌 / 学习 / 睡觉 + 启动
```

## 消息提示音 & 后台通知

在 App「设置」里：

1. **消息提示音**（默认开）  
   收到新消息、来信、来电、邀请等时播放 `assets/notify.wav`。  
   可点「播放测试音（notify.wav）」试听。把你自己的音乐文件改名为 `notify.wav` 放进 `assets/` 即可替换。

2. **后台消息通知**（默认关）  
   打开后会向浏览器申请通知权限。页面在**后台**时弹出系统通知；提示音仍用上面的 wav（系统通知设为静音，避免响两遍）。

3. **后台保活**（默认关）  
   用极低音量循环，减轻浏览器把页面挂起的情况，方便主动消息定时器继续跑。

说明：手机锁屏后系统仍可能暂停网页，请尽量允许通知，并保留页面在后台任务中。
